# Recalled

Vocabulary Trainer — v1.0
Описание

Веб-приложение для изучения английских слов. Пользователь ведёт личный словарь и тренируется по нему.

Функциональные требования
Приложение должно устанавливаться на домашний экран устройства и работать без подключения к интернету.
Пользователь может добавить слово с переводом через форму. Пустые поля при сабмите не допускаются.
Список всех слов отображается на главной странице. Для каждого слова доступны действия: удалить и переключить статус (выучено / не выучено). Выученные слова визуально отличаются от остальных.
Отдельная страница — режим тренировки. Показывает по одному слову из невыученных. Пользователь отмечает — запомнил или нет. Если запомнил — слово получает статус выучено. Кнопка "вернуть к изучению" на главной снимает этот статус обратно. Если невыученных слов нет — показывается соответствующее сообщение.
При потере соединения приложение не падает. Пользователь видит актуальное состояние из кэша.

Нефункциональные требования
Данные хранятся на сервере. Локальный стейт-менеджмент через Redux.
Навигация между страницами без перезагрузки.
Приложение доступно по HTTPS.
